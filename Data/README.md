# Data Source & Documentation

## Overview
This folder documents the dataset used in the **Nigeria Messy Sales Dashboard** project, built using Microsoft Power BI.

The dataset is sourced from Kaggle and is used to demonstrate data cleaning, transformation, data modeling, and sales analysis.

## Dataset Information

- **Dataset Name:** Nigeria Messy Sales Dataset
- **Source Platform:** Kaggle
- **Dataset Author:** Jubair Ahmed *(verify against the original Kaggle page)*
- **Dataset URL:** https://www.kaggle.com/datasets/jubairahmed010/nigeria-messy-sales-dataset
- **License:** Refer to the license displayed on the original Kaggle dataset page.

## How to Obtain the Dataset

1. Visit the Kaggle dataset page linked above.
2. Review the dataset's license and terms of use.
3. Download the dataset files.
4. Place the required CSV file in your local data folder.
5. Update the source path in Power Query if required.
6. Refresh the Power BI report to load the data.

## How the Dataset Is Used

The dataset supports the following project activities:

- Cleaning missing, inconsistent, or messy sales data.
- Transforming data using Power Query.
- Creating sales calculations and DAX measures.
- Building a data model for business intelligence reporting.
- Analyzing sales performance and trends.

## Data Preparation

The dataset may require cleaning and transformation before analysis. Any changes made during the project should be documented in the Power Query steps and relevant project documentation.
